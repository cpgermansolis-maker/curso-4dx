## El hilo conductor

```
Módulo 0 → ¿Cómo funciona esto realmente?
Módulo 1 → ¿Cómo le hablo para que me entienda?
Módulo 2 → ¿Cómo trabajo CON él, no solo le pido?
Módulo 3 → ¿Cómo hago que trabaje sin que yo esté?
Módulo 4 → ¿Cómo convierto todo esto en un sistema propio?
```

---

## Alumno objetivo

Profesional independiente hispanohablante que ya usa Claude (Chat, Co-work, Code) pero solo en nivel básico. Sus 4 dolores:
1. Gasta tokens por ineficiencia
2. Sus prompts generan respuestas genéricas
3. No sabe qué herramienta usar para cada tipo de tarea
4. Le falta vocabulario técnico para seguir aprendiendo solo
