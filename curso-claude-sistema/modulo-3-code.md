## LECCIÓN 19
### "Claude Code no es para programadores — es para ti"

---

**EL ANZUELO**

Escuchar "Claude Code" probablemente te hizo pensar: "eso no es para mí, yo no sé programar." Ese es exactamente el malentendido que esta lección va a destruir. Claude Code no es una herramienta para escribir software. Es el primer asistente de IA que puede abrir tu computadora, entrar a tus carpetas y hacer cosas reales — sin que tú muevas un dedo.

---

**EL CONCEPTO**

Hay una diferencia fundamental entre los tres modos de Claude, y vale la pena decirla con total claridad.

Claude Chat es como llamar a un experto por teléfono. Le describes tu problema, él te da consejo, tú vas y lo ejecutas. La respuesta siempre queda dentro de la conversación.

Claude Projects es como ese mismo experto, pero que ya conoce tu empresa. Recuerda lo que le dijiste la semana pasada, tiene tus documentos de referencia guardados, y cuando le preguntas algo, ya tiene contexto.

Claude Code es diferente a los dos. Claude Code no te dice qué hacer. Claude Code lo hace.

Piénsalo así: imagina que contratas a un asistente administrativo muy competente. No solo te responde preguntas — entra a tu oficina, abre los cajones, reorganiza los archivos, crea los documentos, mueve lo que hay que mover. Y lo hace en segundos.

Eso es exactamente Claude Code. Es un agente — no un chatbot. Tiene acceso a tu sistema de archivos, puede leer y escribir documentos, puede ejecutar instrucciones en tu computadora, y puede encadenar tareas complejas una tras otra sin que tú tengas que supervisar cada paso.

El nombre tiene la culpa del malentendido. "Code" suena a programación. Pero el nombre viene de que, en su origen, se creó para que los programadores automatizaran tareas de software. Lo que nadie anticipó es que las mismas capacidades son enormemente útiles para personas que no escriben ni una línea de código.

¿Quién usa Claude Code hoy, en el mundo real, sin saber programar?

Equipos de ventas que tienen 400 propuestas en PDF y necesitan extraer el monto, el cliente y el estado de cada una.

Consultores que reciben carpetas con 200 documentos de un cliente y necesitan organizarlos antes de la primera reunión.

Coaches que tienen meses de notas de sesiones en archivos de Word dispersos y quieren un resumen consolidado por cliente.

Analistas freelance que reciben hojas de cálculo cada semana y necesitan limpiarlas, formatearlas y cruzar datos — sin tocar una fórmula.

La diferencia clave no es técnica. Es de mentalidad. Con Claude Chat, tú eres el que ejecuta. Con Claude Code, Claude Code ejecuta. Tú solo describes qué quieres que suceda.

Un último punto importante: Claude Code trabaja en un proyecto. Un proyecto es simplemente una carpeta de tu computadora. Le dices a Claude Code "trabaja en esta carpeta" y él tiene acceso a todo lo que hay ahí. Eso es todo. No hay instalaciones complicadas, no hay configuraciones raras. Una carpeta, una instrucción, un resultado.

---

**LA DEMO**

*El instructor abre Claude Desktop App en Windows 11.*

1. Abrir Claude Desktop App desde el menú de inicio o el ícono en la barra de tareas.
2. Observar las opciones disponibles en la pantalla de inicio: Chat, Projects, y la opción para iniciar una sesión de Claude Code.
3. Hacer clic en el ícono de herramientas (el ícono de martillo o "Tools") para iniciar Claude Code.
4. Mostrar una carpeta real en el escritorio — por ejemplo, "Proyectos Clientes 2025" — que contiene 15-20 archivos con nombres caóticos y sin organización.
5. En la ventana de Claude Code, escribir exactamente esta instrucción: *"Dime cuántos archivos hay en mi carpeta Proyectos Clientes 2025 y qué tipos de archivo son."*
6. Mostrar cómo Claude Code entiende la instrucción, accede a la carpeta y devuelve un reporte detallado — sin que el instructor haya escrito código.
7. Comparar visualmente: en Claude Chat, la misma pregunta daría una respuesta genérica. En Claude Code, da una respuesta basada en los archivos reales de esa carpeta.
8. Señalar la diferencia clave en la interfaz: en Claude Code hay una línea que dice qué archivos está leyendo y qué acciones está ejecutando — esto es la "huella" de que está actuando, no solo respondiendo.

---

**TU TURNO**

Abre Claude Desktop App y llega a la sección de Claude Code. Elige la carpeta más caótica o más cargada de archivos que tengas en tu computadora — no importa si está desordenada, de hecho mejor si lo está. Dale a Claude Code esta instrucción exacta:

*"Analiza esta carpeta y dime: cuántos archivos hay, de qué tipos, cuáles son los tres más recientes y cuáles son los tres más antiguos."*

**Criterio de éxito:** Claude Code te devuelve un análisis real de los archivos de tu carpeta, con nombres y fechas reales. No una respuesta genérica — información concreta de tus archivos.

---

**EL INSIGHT DE CIERRE**

> *"Claude Code no escribe código — ejecuta órdenes. Y la diferencia entre decirle a alguien qué hacer y que alguien lo haga por ti vale exactamente las horas que llevas haciéndolo solo."*

## LECCIÓN 20
### "CLAUDE.md — el contrato que hace que Claude trabaje exactamente como tú quieres"

---

**EL ANZUELO**

¿Alguna vez le has explicado a alguien cómo trabajas, cómo organizas tus archivos, qué cosas nunca tocar — y al día siguiente tienes que explicarlo otra vez? Con Claude Code sin configurar, ese ciclo se repite en cada sesión. CLAUDE.md es el archivo que termina con eso para siempre.

---

**EL CONCEPTO**

Imagina que contratas a alguien para que te ayude con tu trabajo. El primer día llega con buena voluntad pero sin contexto. No sabe cómo nombras tus archivos, no sabe qué carpetas son sagradas, no sabe que a ti te gusta recibir un resumen antes de hacer cualquier cambio importante. Podrías explicarle todo el primer día... y rezar para que lo recuerde la semana siguiente.

O podrías darle un documento. Un manual de trabajo. Un contrato que dice: "Así es como funciona este espacio. Esto es lo que puedes hacer. Esto es lo que nunca debes tocar. Estas son mis preferencias. Y si tienes dudas sobre algo importante, pregunta antes de actuar."

Eso es exactamente CLAUDE.md.

CLAUDE.md es un archivo de texto — un documento simple — que vive dentro de tu carpeta de proyecto. Claude Code lo lee automáticamente cada vez que empieza una sesión de trabajo en esa carpeta. No tienes que mencionarlo, no tienes que cargarlo, no tienes que repetir tus instrucciones. Están ahí, permanentes, desde el primer momento.

¿Por qué esto importa tanto?

Porque Claude Code sin instrucciones es como una persona muy capaz pero que no conoce tu negocio. Puede hacer cosas incorrectas — no por error técnico, sino por falta de contexto. Puede renombrar archivos que no debía tocar. Puede usar un formato que no es el tuyo. Puede hacer cambios sin avisarte cuando tú preferirías que te consultara primero.

CLAUDE.md es el documento que convierte a un asistente genérico en uno que trabaja exactamente a tu manera.

Ahora la pregunta práctica: ¿qué se escribe en un CLAUDE.md?

No se escribe código. No hay sintaxis especial. Se escribe en lenguaje natural, como si le hablaras a una persona. Claude Code entiende instrucciones en español, en lenguaje conversacional, sin tecnicismos.

Un CLAUDE.md básico para un consultor independiente podría decir algo así:

*"Esta carpeta contiene los proyectos activos de mis clientes. Los archivos importantes nunca deben borrarse sin pedirme confirmación explícita. Cuando renombres archivos, usa siempre este formato: AAAA-MM-DD_NombreCliente_Descripción. Las carpetas principales son: Propuestas, Contratos, Entregas, y Archivo. Antes de mover más de 5 archivos a la vez, muéstrame el plan y espera mi aprobación. Si algo no está claro, pregunta."*

Eso es todo. Lenguaje natural, instrucciones concretas, sin una sola línea de código.

Hay un concepto adicional que vale mucho la pena entender: la Auto Memory de Claude Code. Claude Code no solo lee tu CLAUDE.md — también puede escribir en él. Cuando descubre algo sobre cómo trabajas, cuando le corriges algo, cuando le dices "de ahora en adelante siempre hazlo así", Claude Code puede agregar esa instrucción al CLAUDE.md para que quede registrada. Está construyendo su propia memoria de tus preferencias. Tu asistente no solo aprende — documenta lo que aprendió.

Sin CLAUDE.md, cada sesión empieza de cero. Con CLAUDE.md, cada sesión empieza exactamente donde dejaste tu estándar de trabajo.

---

**LA DEMO**

*El instructor abre una carpeta de proyecto real en Windows 11.*

1. Mostrar la carpeta del proyecto: por ejemplo, "Consultoría Clientes 2025" con subcarpetas y archivos variados.
2. Abrir el Bloc de notas (Notepad) de Windows. Ir a Inicio → buscar "Bloc de notas" y abrirlo.
3. Escribir un CLAUDE.md en vivo, explicando cada sección mientras se escribe:

```
# Mi Espacio de Trabajo — Consultoría

## Quién soy
Soy consultor independiente. Trabajo con clientes corporativos.
Mis proyectos duran entre 2 y 6 meses.

## Cómo organizo mis archivos
- Formato de nombre para archivos: AAAA-MM-DD_Cliente_Descripción
- Ejemplo correcto: 2025-11-15_Empresa-ABC_Propuesta-Inicial
- Las carpetas principales son: /Propuestas, /Contratos, /Entregas, /Archivo

## Reglas importantes
- NUNCA borres ningún archivo sin pedirme confirmación
- NUNCA muevas más de 10 archivos a la vez sin mostrarme el plan primero
- Si un archivo ya tiene el formato correcto de nombre, no lo cambies
- Los archivos en /Archivo son históricos — no los muevas ni modifiques

## Antes de hacer cambios grandes
Muéstrame qué vas a hacer, espera que yo diga "adelante", luego hazlo.

## Mi idioma
Siempre respóndeme en español latinoamericano.
```

4. Guardar el archivo: Archivo → Guardar como → navegar a la carpeta del proyecto → nombre del archivo: `CLAUDE.md` → Tipo: "Todos los archivos" → Guardar.
5. Mostrar que el archivo ahora aparece dentro de la carpeta del proyecto.
6. Abrir Claude Code y apuntarlo a esa carpeta.
7. Sin decir nada sobre el CLAUDE.md, escribir: *"¿Qué instrucciones tienes para trabajar en esta carpeta?"*
8. Mostrar cómo Claude Code menciona las instrucciones del CLAUDE.md — lo leyó automáticamente al inicio de la sesión.

---

**TU TURNO**

Elige la carpeta donde más trabajas — la que abrirías si tu computadora solo pudiera tener una carpeta. Crea un archivo CLAUDE.md dentro de ella usando el Bloc de notas de Windows.

Tu CLAUDE.md debe responder estas cuatro preguntas:
1. ¿Cómo quieres que se llamen los archivos?
2. ¿Qué carpetas son las principales?
3. ¿Qué nunca debe tocar sin preguntarte?
4. ¿Qué debe hacer antes de ejecutar cambios grandes?

No te preocupes por la perfección — puedes editarlo después. El objetivo es tener la primera versión.

**Criterio de éxito:** Abres Claude Code, lo apuntas a tu carpeta, le preguntas "¿qué instrucciones tienes?" y él te menciona lo que escribiste en el CLAUDE.md.

---

**EL INSIGHT DE CIERRE**

> *"Un asistente sin instrucciones trabaja con sus supuestos. Uno con instrucciones trabaja con los tuyos."*

## LECCIÓN 21
### "Las 5 automatizaciones que todo profesional independiente debería tener"

---

**EL ANZUELO**

Hay tareas que haces cada semana, o cada mes, que consumen entre 30 minutos y 3 horas de trabajo manual puro. Renombrar archivos. Abrir PDFs para copiar datos. Darle formato a documentos. Estas no son tareas que requieran tu criterio — requieren tu tiempo. Esta lección es el mapa de las cinco que puedes eliminar hoy.

---

**EL CONCEPTO**

Hay un tipo de trabajo que los profesionales independientes hacemos constantemente y que nadie celebra: el trabajo de preparación. Antes de la reunión, hay que organizar los documentos. Antes de la factura, hay que revisar los PDFs. Antes del reporte, hay que limpiar la hoja de cálculo. Antes de entregar, hay que darle formato al documento.

Este trabajo no aporta valor al cliente. Aporta orden para que tú puedas hacer el trabajo que sí aporta valor. Pero lo hacemos nosotros porque nunca tuvimos a alguien — o algo — que lo hiciera.

Claude Code puede hacer exactamente este tipo de trabajo. No el trabajo estratégico, no las decisiones, no la relación con el cliente. Pero sí la preparación. Y la preparación se puede describir en lenguaje natural.

Las cinco automatizaciones que siguen no requieren que sepas programar. Requieren que sepas describir qué quieres. Y eso, ya lo sabes hacer.

---

**Automatización 1: Organización masiva de archivos**

La instrucción:
*"Revisa todos los archivos de esta carpeta. Renombra cada uno usando el formato: AAAA-MM-DD_Tipo_Descripción-corta, donde Tipo puede ser Propuesta, Contrato, Factura u Otro según el contenido del archivo. Luego crea subcarpetas con esos nombres y mueve cada archivo al lugar correcto. Antes de mover nada, muéstrame el plan completo para que yo lo apruebe."*

---

**Automatización 2: Extracción de datos de PDFs en lote**

La instrucción:
*"Abre todos los PDFs de esta carpeta. De cada uno extrae: nombre del proveedor, fecha de la factura, número de factura y monto total. Crea un archivo Excel llamado Resumen-Facturas con esa información, una fila por factura. Si algún PDF no tiene esos datos claramente, márcalo como 'revisar manualmente'."*

---

**Automatización 3: Generación automática de documentos de negocio**

La instrucción:
*"Tengo un archivo llamado plantilla-propuesta.docx y un archivo llamado clientes.xlsx con los datos de 20 clientes. Crea una propuesta individual para cada cliente, reemplazando los campos [NOMBRE], [EMPRESA], [SERVICIO] y [MONTO] con los datos correspondientes de la hoja de cálculo. Guarda cada propuesta con el nombre: Propuesta_NombreCliente_2025.docx"*

---

**Automatización 4: Procesamiento de hojas de cálculo en lenguaje natural**

La instrucción:
*"Abre el archivo ventas-octubre.xlsx. Elimina filas duplicadas. Suma el total por categoría y ponlo en una hoja nueva llamada 'Resumen'. Ordena la hoja original por fecha de más reciente a más antiguo. Agrega una columna al final llamada 'Prioridad': si el monto es mayor a $5,000 escribe 'Urgente', si no escribe 'Normal'. Guarda el archivo con el nombre ventas-octubre-limpio.xlsx."*

---

**Automatización 5: Reportes automáticos desde carpetas de archivos**

La instrucción:
*"Revisa todas las subcarpetas de mi carpeta Proyectos. Para cada una, dime: cuántos archivos tiene, cuál fue la última modificación, y si la última modificación fue hace más de 30 días márcala como 'sin actividad reciente'. Genera un reporte en formato Word llamado Reporte-Semanal-[fecha de hoy].docx con esa información organizada en una tabla."*

---

**LA DEMO**

*El instructor tiene preparada una carpeta llamada "Facturas-Demo" con 8 PDFs de facturas ficticias con nombres como "doc001.pdf", "archivo_final.pdf", "factura.pdf".*

1. Mostrar la carpeta antes: archivos sin nombres descriptivos, mezclados, sin orden.
2. Abrir Claude Code y apuntarlo a la carpeta "Facturas-Demo".
3. Escribir la instrucción de la Automatización 2 adaptada a esos archivos.
4. Mostrar cómo Claude Code lee cada PDF uno por uno (se puede ver el progreso en tiempo real).
5. Mostrar el archivo Excel generado automáticamente con todos los datos extraídos.
6. Volver a mostrar la carpeta original — los archivos siguen intactos, solo se generó el reporte nuevo.
7. Señalar el tiempo total que tomó: menos de 2 minutos para 8 facturas.

---

**TU TURNO**

Elige la automatización que resuelve tu dolor más grande de las cinco. Identifica la carpeta de tu computadora donde está ese problema hoy. Adapta la instrucción correspondiente con los nombres de tus archivos reales y ejecútala.

**Criterio de éxito:** Claude Code completó la tarea y el resultado es usable — los archivos están organizados, el Excel tiene los datos correctos, o el reporte existe y tiene sentido.

---

**EL INSIGHT DE CIERRE**

> *"La tarea que más tiempo te roba no es la más difícil — es la más repetitiva. Y lo repetitivo se puede delegar."*

## LECCIÓN 22
### "MCP — conecta Claude con todo lo que ya usas"

---

**EL ANZUELO**

Claude Code ya puede trabajar con los archivos de tu computadora. Pero ¿qué pasa con los documentos que viven en Google Drive? ¿Con los mensajes de Slack? ¿Con tu base de datos de clientes? MCP es el puente que conecta a Claude con todas esas herramientas — y la conexión se hace sin escribir código.

---

**EL CONCEPTO**

MCP significa "Model Context Protocol". La analogía que lo explica mejor: MCP es el USB-C de la inteligencia artificial.

El USB-C es un estándar de conexión. No importa si conectas un monitor, un disco duro externo, una cámara o un teclado — todos usan el mismo tipo de cable. MCP funciona igual, pero para herramientas digitales. Es un estándar que define cómo cualquier aplicación puede conectarse con Claude.

Los conectores MCP se llaman "servidores MCP". Hoy existen más de 300 disponibles. Los más relevantes para el profesional independiente:

**Google Drive:** Claude puede leer documentos, hojas de cálculo y presentaciones directamente desde tu Drive sin descargarlos.

**Slack:** Claude puede leer canales, buscar mensajes, y enviar notificaciones automáticas.

**Notion:** Claude puede leer tus páginas, crear nuevas entradas, y actualizar bases de datos.

**Bases de datos:** Con el servidor MCP correcto, Claude puede consultarlas con instrucciones en lenguaje natural. Sin SQL, sin código.

¿Cómo se conecta? En el Desktop App de Claude hay una sección de configuración donde puedes agregar servidores MCP. Para cada servicio, buscas el servidor MCP correspondiente, sigues las instrucciones de instalación (escritas para personas no técnicas), autorizas la conexión, y listo.

---

**LA DEMO**

1. Abrir Claude Desktop App. Ir al menú de configuración.
2. Mostrar la sección de "Integrations" o "MCP Servers".
3. Navegar a `modelcontextprotocol.io/servers` en el navegador.
4. Buscar "Google Drive" en ese directorio. Mostrar la página del servidor.
5. Mostrar cómo se agrega el servidor en la configuración del Desktop App.
6. Una vez conectado, abrir Claude Code y escribir: *"¿A qué herramientas tienes acceso ahora?"*
7. Mostrar que Claude Code lista Google Drive entre sus herramientas disponibles.
8. Prueba en vivo: *"Dime cuántos archivos hay en mi Google Drive y cuáles fueron modificados esta semana."*

---

**TU TURNO**

Visita `modelcontextprotocol.io/servers`. Identifica una herramienta que uses en tu trabajo diario. Lee la descripción del servidor MCP correspondiente y escribe:

- El nombre de la herramienta que elegiste
- Un caso de uso concreto donde Claude + esa herramienta te ahorraría tiempo

**Criterio de éxito:** Puedes describir con una oración concreta qué haría Claude si estuviera conectado a esa herramienta.

---

**EL INSIGHT DE CIERRE**

> *"Las herramientas que ya usas no cambian. Lo que cambia es que ahora tienen un intérprete común: Claude."*

## LECCIÓN 23
### "Rutinas — tareas que corren solas aunque apagues la computadora"

---

**EL ANZUELO**

Hasta ahora, todas las automatizaciones de Claude Code las inicias tú. Las Rutinas cambian eso: son tareas que corren en un horario fijo, en la infraestructura de Anthropic, sin que tu computadora esté encendida. Como tener un asistente que trabaja de noche.

---

**EL CONCEPTO**

Una automatización manual es como un electrodoméstico: lo enciendes cuando lo necesitas. Una rutina es como programar el horno: lo configuras una vez y ya no tienes que estar ahí para que funcione.

Las Rutinas de Claude Code corren en los servidores de Anthropic — no en tu computadora. Aunque tu laptop esté apagada, la rutina se ejecuta en el horario que configuraste.

Casos de uso para el profesional independiente:

**Reporte diario de proyectos.** Cada mañana a las 7 AM, Claude revisa tu carpeta de proyectos, ve qué cambió en las últimas 24 horas, y genera un resumen que encuentras esperándote.

**Resumen semanal.** Cada viernes a las 6 PM, Claude revisa todo lo que llegó durante la semana y genera un resumen consolidado.

**Alerta de archivos modificados.** Una rutina que revisa tus contratos cada día y te avisa si algo fue modificado sin tu autorización.

**Limpieza semanal de descargas.** Una rutina que organiza automáticamente lo que acumulaste durante la semana.

¿Cómo se configura? En la sección de Claude Code del Desktop App hay una opción para crear rutinas. El proceso: describir en lenguaje natural qué debe hacer, definir el horario, especificar en qué carpeta debe trabajar. No hay código.

---

**LA DEMO**

1. Abrir Claude Desktop App. Ir a la sección de Claude Code.
2. Mostrar la opción de "Routines" o "Scheduled Tasks".
3. Hacer clic en "Nueva rutina".
4. Configurar en vivo: "Cada lunes a las 8 AM, revisa la carpeta Proyectos-Activos, cuenta cuántos archivos hay por subcarpeta, y crea un archivo llamado Inicio-Semana-[fecha].txt con ese resumen."
5. Seleccionar horario: "Cada semana" → "Lunes" → "8:00 AM".
6. Guardar la rutina.
7. Ejecutar manualmente para mostrar el resultado.
8. Señalar: "Este archivo va a estar esperándote cada lunes por la mañana, sin que hagas nada."

---

**TU TURNO**

Piensa en una tarea de resumen o monitoreo que haces regularmente. Escribe la descripción de esa tarea como si se la explicaras a un asistente: qué carpeta debe revisar, qué información recopilar, qué formato debe tener el resultado, con qué frecuencia.

**Criterio de éxito:** Tienes una descripción de rutina en lenguaje natural que Claude Code entendería exactamente.

---

**EL INSIGHT DE CIERRE**

> *"El trabajo que no requiere tu presencia no debería requerir tu presencia."*

## LECCIÓN 24 — CASO PRÁCTICO CODE
### "100 archivos organizados en 2 minutos — en vivo"

---

**EL ANZUELO**

Todo lo que aprendiste en este módulo converge aquí. En los próximos minutos vas a ver una carpeta caótica transformarse en un sistema organizado — con una sola instrucción en lenguaje natural. Luego lo vas a replicar con la carpeta más desordenada que tengas.

---

**EL CONCEPTO**

Hay un momento en el que la teoría se convierte en algo real. Esta lección es ese momento.

Claude Code no clasifica archivos por extensión ni por fecha — clasifica por contenido. Sabe si un PDF es una factura, un contrato o una propuesta porque lo leyó. Y antes de mover un solo archivo, te muestra el plan y espera tu aprobación.

---

**LA DEMO**

*El instructor tiene preparada una carpeta "CAOS-Demo" con 25 archivos con nombres como "doc_final_v3.docx", "presentacion_ese.pptx", "scan0047.pdf", mezclados sin orden.*

1. Mostrar la carpeta antes — el caos es evidente.
2. Abrir Claude Code. Primera instrucción: *"Analiza todos los archivos de esta carpeta. Sin mover nada todavía, dime: cuántos archivos hay, de qué tipos son, y cómo los clasificarías en categorías lógicas."*
3. Mostrar el análisis: Claude "leyó" los archivos y propone categorías.
4. Segunda instrucción: *"Ahora organizá esta carpeta: creá las subcarpetas que propusiste, renombrá cada archivo con el formato AAAA-MM-DD_Categoría_Descripción. Mostrá el plan completo antes de mover cualquier cosa."*
5. Revisar el plan en voz alta. Hacer una corrección en vivo.
6. Escribir: *"Adelante, ejecutá el plan."*
7. Mostrar ejecución en tiempo real.
8. Mostrar la carpeta después: subcarpetas creadas, archivos renombrados.
9. Contar el tiempo total: generalmente entre 90 segundos y 3 minutos para 25 archivos.

---

**TU TURNO**

Busca la carpeta más caótica que tengas — más de 20 archivos sin orden. Toma captura de pantalla antes. Dale a Claude Code esta instrucción:

*"Analiza esta carpeta. Sin mover nada todavía, dime cómo organizarías estos archivos: qué categorías crearías, qué formato de nombre usarías, y qué harías con los archivos duplicados o los que parezcan temporales. Espera mi aprobación antes de hacer cualquier cambio."*

Revisa el plan. Corrígelo. Aprueba. Ejecuta. Toma captura después.

**Criterio de éxito:** La carpeta está estructurada con nombres descriptivos — sin haber escrito una línea de código.

---

**EL INSIGHT DE CIERRE**

> *"El desorden no desaparece cuando tienes más tiempo. Desaparece cuando tienes la herramienta correcta."*

## EJERCICIO INTEGRADOR — MÓDULO 3
### "Tu sistema de trabajo en Claude Code — del caos al estándar"

1. ¿Qué tipo de trabajo se hace en esta carpeta?
